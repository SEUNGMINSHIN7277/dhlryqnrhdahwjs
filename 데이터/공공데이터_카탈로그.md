# 외교부·KOICA·KF·한·아프리카재단 개방데이터 카탈로그 (실조회 확인본)

본 문서는 「케이서클(K-Circle)」이 활용하는 4개 주관기관 개방데이터를 실제 조회로 확인·정리한 카탈로그입니다.

## 조회 방법 및 봇 차단 관련 고지 (투명성)
- 대상 포털(`www.data.go.kr`, `opendata.mofa.go.kr`, `insight.mofa.go.kr`, `k-af.or.kr`)은 **봇 차단(WAF)으로 HTTP 403**을 반환하며, 본 실행환경의 **이그레스 게이트웨이 정책**이 해당 호스트로의 CONNECT를 403으로 거부하여 브라우저(Playwright)·curl 직접 접근도 불가했습니다.
- 이그레스 정책 우회는 금지 사항이므로 시도하지 않았습니다. 실효적 확인 경로는 다음 두 가지였습니다.
  - **검색엔진 색인(WebSearch)**: 403으로 막힌 페이지의 데이터셋명·숫자 ID·설명·응답항목·건수를 스니펫으로 확인.
  - **오픈소스 클라이언트 코드(GitHub) 교차검증**: 실제로 해당 API를 호출·파싱하는 코드에서 **정확한 응답 필드 키**를 확인(여행경보·안전정보·재외공관 계열은 ground-truth).
- 실서비스에서는 **공공데이터포털 활용신청 → serviceKey 발급 → `apis.data.go.kr` 직접 호출**로 데이터를 확보합니다.
- data.go.kr 제공기관 코드: **외교부=1262000, KOICA=B260002/B260003, KF=B260004, 한·아프리카재단=B554031**.

## ★ 융합 설계 핵심
1. **ISO 3166-1 국가코드(`country_iso_alp2`) = 4개 기관 공통 조인키.** 외교부 국가표준코드(15091117)를 마스터로 KF·KOICA·아프리카재단 데이터를 국가 단위 결합 → 통합 국가 프로파일.
2. **정부가 이미 만든 융합 데이터셋** 15099199(KF측)·15099215(KOICA측)이 KF×KOICA 조인 레퍼런스 → 공공외교/ODA 중복·공백 분석에 즉시 활용.
3. **MOFA LOD 온톨로지(국가·연도·조직·사건)** 를 시맨틱 백본으로 SPARQL 연계 가능.

## 검증 신뢰도
- **Ground-truth(실제 필드 키 확인)**: 외교부 여행경보(15095500·15059195)·안전정보(15000760)·재외공관(15075354) 계열.
- **포털 명세 기준(응답 항목 한글명 확보)**: KOICA 전 계열·주요인사교류·공석정보·KF·한·아프리카재단.
- 영문 응답 키 일부·엔드포인트명은 실인증키 발급 후 직접 호출로 최종 확정 가능.
