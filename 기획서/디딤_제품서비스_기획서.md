## 1. 제품(서비스)의 목적·배경 및 필요성

### 1.1 문제 정의 — "가고 싶지만, 갈 지도가 없다"
- 중소기업 해외진출 애로 조사에서 **1위 '현지 정보 부족', 2위 '정부 지원제도 미흡'**. 바이어 발굴(34.6%)·해외시장 정보 부족(33.4%)·글로벌 역량 미흡(19.6%)이 반복 지적됨.
- 반대로 중소기업의 **46.1%가 동남아·중동·중남미·CIS·아프리카 등 신흥시장 개척 의향** → 수요는 크나 진입 정보·역량의 벽이 높음.
- 신흥시장·개발협력 정보는 **여러 기관에 파편화**: 사업기회는 KOICA, 국가·안전 정보는 외교부, 소프트파워·현지 네트워크는 KF, 아프리카 특화 정보는 한·아프리카재단. **이를 국가 단위로 연결해 주는 서비스가 부재.**

### 1.2 시장·정책적 필요성
- 2026년 우리나라 ODA 예산 약 **2조 1,852억원**(KOICA 약 1조 1,389억원) + **400억 달러 이상**의 다자개발은행(MDB) 조달시장이 열려 있으나, 정보·제안 역량 부족으로 중소기업·소셜벤처의 참여가 제한적.
- 예산 효율화 기조 속 **민간·중소기업의 개발협력 참여 확대·성과 제고**가 정책적으로 더 중요 → 민간의 진입 비용을 낮추는 디지털 인프라 필요.
- 외교부·KOICA·KF·한·아프리카재단이 **양질의 공공데이터를 이미 개방**하고 있으나 개별 API/파일로 흩어져 일반 기업·청년이 직접 활용하기 어려움 → **AI 융합 서비스로 '활용의 마지막 1마일'을 연결**할 필요.

### 1.3 동기
- 개방 데이터를 '조회'에 머무르지 않게 하고, **실제 사업 의사결정·제안서 작성까지 잇는 실행 도구**로 전환하면 데이터 경제 활성화·신규 창업 촉진이라는 본 대회 취지에 정면 부합.
- "정보 격차 때문에 세계로 못 나가는" 중소기업·소셜벤처·청년에게 **디딤돌**을 놓자는 것이 제품명 '디딤'의 취지.

## 2. 제품(서비스)의 기능 및 특징

### 2.1 제품 개념
> **디딤 = 외교·개발협력 공공데이터 융합 레이어 + AI 인텔리전스 엔진 + 실행형 워크스페이스**
> 기업이 "**어디로, 어떤 사업을, 누구와, 어떻게 안전하게**" 나갈지를 데이터 근거와 함께 답해 주는 SaaS.

### 2.2 시스템 아키텍처
```
[공공데이터 소스]                              [디딤 플랫폼]                          [사용자]
외교부 1262000 (여행경보/안전/공관/국가정보) ─┐  ┌──────────────────────────┐
KOICA  B260002·3 (사업/조달/동향/통계/연구)  ─┼─►│ ① 데이터 파이프라인(ETL)   │
KF     B260004 (공공외교/융합/한류/한국학)   ─┤  │  · ISO2 국가코드 표준화     │
한·아프리카재단 B554031 (스타트업/250대기업) ─┘  │  · 관계형DB + 벡터DB        │
                                                 └────────────┬─────────────┘
                                                              ▼
                            ┌─────────────────────────────────────────────┐
                            │ ② AI 인텔리전스 엔진                          │

                            │  · 리스크 스코어링(여행경보 히스토리 시계열)  │   (중소기업·소셜
```

- **공통 조인키 = ISO 3166-1 국가코드(`country_iso_alp2`).** 외교부 국가표준코드(15091117·15075346)를 마스터로 4개 기관 데이터를 국가 단위로 자동 결합 → "**소프트파워+개발협력+외교활동+안전**"의 통합 국가 프로파일 생성.

### 2.3 5대 핵심 기능 모듈 (모듈별 활용 데이터 명시)

**① 디딤 매치 — 맞춤 사업기회 매칭 엔진**
- 기업 프로필(업종·역량·관심지역·인증·규모) 입력 → **KOICA 사업정보(15058772)·ODA 조달정보(3039908)·국가별 개발협력동향(15075386, KOICA 12대 분야)** 및 **KF×KOICA 융합 사업정보(15099199·15099215)** 와 매칭.
- AI가 '나에게 맞는 사업기회 Top N + 적합도 근거'를 추천(임베딩 유사도 + 자격/섹터/지역 규칙 필터).

**② 디딤 인텔 — 국가·리스크 진출 브리핑**
- 국가 선택 시 **외교부 국가기본정보(15000830: 수도·인구·통화)·여행경보(15095500: `alarm_lvl` 1~4)·국가별 안전정보(15000760)·입국허가요건(15075345)·다자조약/사증면제(15099237·15099235)** + **KOICA 개발협력동향(15075386)** + **한·아프리카재단 250대기업(15099200)·스타트업 디렉터리(15099203)** 를 LLM이 종합.
- '진출 브리핑(시장·정치·안전·규제·현지 지원창구)'을 자동 생성, **모든 문장에 공공데이터 출처 각주(RAG)**.

**③ 디딤 코파일럿 — 제안서·사업계획 AI 작성 도우미**
- 선택 기회에 대해 **KOICA ODA 연구정보(15052906)·국별사업 보고서(15052832)·MOFA LOD countryInfo(국가정보)** 를 근거(RAG)로 **개념노트(Concept Note)·사업계획 초안·로그프레임·SDGs 매핑**을 생성.

**④ 디딤 커넥트 — 파트너·인재·소프트파워 네트워크**
- 대·중소·소셜벤처 **컨소시엄 매칭**.
- **KF 분야별 한류현황(15076252)·국가별 동호회(15076250)·해외 한국학 과정(15041591)·공공외교 사업(15099202)** 을 **현지 진입 노드(친한 네트워크·한국어교육기관·동문)** 로 연결.
- **KOICA 해외봉사단 파견기관 정보(15076248)**·외교부 **분야별 공석정보(15057115)·JPO 공석(15058737)** 로 **글로벌 인재풀** 연계.
- **한·아프리카재단 지자체 교류협력 사례(15113634)** 로 지자체·공공 파트너 매칭.

**⑤ 디딤 세이프 — 파견 안전관리(Duty of Care)**
- 진출·파견 단계에서 **외교부 여행경보(15095500)·경보 히스토리(15059195)·국가별 안전정보(15000760)·재외공관 정보(15075354: `embassy_lat/lng`, `urgency_tel_no`)** + **KOICA 현지 안전정보(15099207)·파견국 안전이슈 월력표(15076240)** 로 실시간 리스크 모니터링·경보 알림·위기 시 최근접 공관 연계.

### 2.4 AI 기술 특징
- **RAG 기반 출처 각주**: 모든 AI 응답에 활용 공공데이터 출처를 각주 표기 → 환각(hallucination) 억제, 공공데이터 신뢰성 계승(설명가능한 AI).
- **국가 리스크 스코어링**: 여행경보 히스토리(`alarm_lvl`+`written_dt` 시계열)로 국가별 '진출 난이도·안전 지수' 산출. 안전공지 급증을 경보 상향 **선행지표**로 활용.
- **멀티에이전트**: 매칭·브리핑·작성 에이전트를 오케스트레이션해 '기회 발견 → 국가 분석 → 제안서 초안'을 한 흐름으로 처리.
- **한·영 이중언어**: 국내 사용자 + 현지·다자기구 제출을 동시 지원.

### 3.2 데이터 확보의 지속성·활용 범위·가공
- **지속성**: 「공공데이터의 제공 및 이용 활성화에 관한 법률」에 근거한 상시 개방·정기 갱신 공식 API/파일 사용. serviceKey 기반 안정 수집 → 서비스 지속성 보장.
- **가공(4단계 파이프라인)**:
  1) **표준화·엔티티 정합**: `country_iso_alp2`/OECD DAC 섹터코드로 기관 간 데이터 결합. 외교부 국가표준코드(15091117)를 마스터 키로 사용.
  2) **벡터 임베딩**: KOICA 연구·보고서, 국가 브리핑 텍스트를 임베딩→벡터DB 적재→RAG 검색.
  3) **시계열 가공**: 여행경보 히스토리(15059195)로 국가 리스크 지수·조기경보 신호 산출.
  4) **정기 ETL·정합성 검증**: 스케줄러가 갱신 주기에 맞춰 자동 수집, 캐시·검증으로 지연/결측 대응.
- **활용 범위·준수사항**: 상업적 재이용이 허용된 개방데이터 범위 내에서 이용약관·출처표시 준수(각주 자동 표기). 개인정보 미포함 데이터 위주로 설계.

## 4. 기존 제품(서비스)과의 차별성 및 독창성

- **국내 유일의 '4개 외교·개발협력 데이터 융합' 인텔리전스**: 사업기회(KOICA)+국가·안전(외교부)+소프트파워(KF)+아프리카 특화(한·아프리카재단)를 국가 단위로 결합한 서비스는 부재.
- **KOTRA·무역협회와의 차별점**: 기존 지원기관은 '무역·수출' 중심. 디딤은 **개발협력(ODA)·다자조달·소프트파워·현지 안전**까지 포괄하는 **'개발협력형 진출' 특화**.
- **기회→제안서 원스톱 코파일럿**: 단순 정보 제공을 넘어 KOICA 실데이터(RAG)로 **개념노트·로그프레임·SDGs 매핑까지 자동 초안** 생성(국내 최초 수준).
- **소프트파워의 자산화(창의적 데이터 재사용)**: KF 한류·한국학·동호회 데이터를 '현지 시장 진입 노드'로 재해석 → 데이터의 새로운 활용 가치 창출.
- **출처 각주형 설명가능 AI(RAG)**: 정부 데이터의 신뢰성을 그대로 계승.
- **정책이 이미 검증한 수요**: 정부 스스로 'KF-공공외교 × KOICA-ODA 융합 데이터셋(15099199·15099215)'을 개방 → 데이터 융합 수요가 실재함을 방증. 그러나 이를 **실행 서비스**로 전환한 사례는 없음 → 디딤이 그 공백을 메움.

## 5. 기대효과 (사회적 가치 창출)

- **상생협력**: 대·중소·소셜벤처 컨소시엄 매칭, 민관 개발협력 파트너십 촉진 → 대기업 편중 완화, 지자체(아프리카 교류)·대학까지 연결.
- **일자리 창출**: ①중소기업·소셜벤처의 해외매출·고용 증가 ②청년의 글로벌·개발협력 커리어(KOICA 봉사단·국제기구·JPO 공석 연계) ③수원국 현지 고용·역량강화.

- **국격·소프트파워**: 민간 주도 개발협력 생태계 형성, K-브랜드·한국형 개발경험의 세계 확산.
- **공공데이터 가치 실현**: 흩어진 외교·개발협력 데이터를 실사용으로 연결 → 데이터 경제 활성화라는 대회 취지 구현.

- 대상 포털(data.go.kr, opendata.mofa.go.kr 등)은 봇 차단(WAF)·실행환경 이그레스 정책으로 직접 접근·브라우저 렌더링이 차단됨(정책 우회 미시도).
