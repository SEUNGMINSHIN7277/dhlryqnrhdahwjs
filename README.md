# 케이무대(K-Stage) — 2026 외교 공공데이터·AI 활용 경진대회 출품작

> **"184개 재외공관이 여는 한류행사를 외교부 데이터로 찾아내, 중소 K-브랜드의 '무대 박스'(샘플 200개+현지어 리플릿+QR)를 그 무대에 실어 보내는 서비스."**
> 이 한 문장이 제품의 전부다.

## 문제 → 솔루션 (1:1)
- **문제 한 장면**: 팬 2,780만의 멕시코, 주멕시코대사관 K-Pop World Festival 예선에 수천 명이 모인다. 그날 팬 손에 쥐어진 진품 K-상품은 **0개** — 팬들이 사는 건 연 97억 달러 규모의 **위조 K-브랜드**다. 아이돌 모델료 20~30억을 못 내는 중소 브랜드 2.8만 개사는 자기 고객이 모이는 이 정부 행사가 열리는지도 모른다.
- **솔루션 하나**: 그 무대에 **박스를 올린다.** 행사를 새로 만들지 않고, 팬을 모으지 않는다 — 정부가 12년째 만들어 온 무대를 **유통망으로 재해석**한다.

## 작동 (3단계)
1. **찾는다**: KF 공공외교 사업정보(15099202)로 공관 행사 이력 맵 + 공관 홈페이지(15075347 시드)에서 AI가 일정 추출
2. **싣는다**: 브랜드가 박스 신청 → AI가 현지어 리플릿·비매품 통관 체크리스트(15075345)·경보(15095500)/공관 연락처(15075354) 키트 생성
3. **증명한다**: 행사 후 QR 스캔·설문 '무대 리포트'

**하지 않는 것**: 역직구몰 ✗ 팬 B2C 앱 ✗ 동호회 매칭 ✗ 한류 지수·대시보드 ✗ — *"박스 없이 성립하는 기능이면 만들지 않는다."*

## 심사 루프 이력 (전 과정 기록)
1기 디딤(28/30) → 2기 SWI 특색 강화 → 3기 한류 재발굴: 후보 9종 R1 전원 불합격 → 케이서클 R2 조건부 → R3 90/90/90 통과 → **지원자 심사 혹평("두루뭉실, 다 하겠다") 반영, v2 하드 게이트(10초 테스트·단일 문제-단일 제품·구체 메커니즘·서늘한 장면) 신설** → 4기: 신규 5종 중 4종 게이트 탈락, **케이무대 단독 통과·처방 7건 전건 반영**. 상세: `기획서/아이디어_발굴_심사표.md`
