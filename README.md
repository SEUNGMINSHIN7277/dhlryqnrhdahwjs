# 디딤(DIDIM) — 2026 외교 공공데이터·AI 활용 경진대회 출품작

> **소프트파워 나침반 — AI 신흥시장·개발협력 진출 플랫폼**
> 한국의 '소프트파워 발자국'을 나침반 삼아, 외교부·KOICA·KF·한·아프리카재단 데이터를 AI로 융합해 **남들이 못 보는 블루오션과 현지 파트너**를 찾아주는 B2B SaaS.

## ★ 우리만의 특색 — 소프트파워 진출지수 (SWI)
`SWI(국가·분야) = 친한자산 A × 사업공백 G × 접근성/리스크 R`
- **친한 자산은 높은데(한류·한국어·ODA) 사업은 비어있는(화이트스페이스) 블루오션**을 점수로 발굴.
- **4개 기관 데이터를 융합해야만 산출 가능** → KOTRA식 일반 데이터로는 복제 불가능한 고유 IP·해자.
- 레드오션(GDP·시장규모)이 아니라 **한국이 유리한 빈 시장**을 "온기 지도"로 시각화.

## 응모 정보
- **대회**: 2026년 외교 공공데이터·AI 활용 경진대회 (주최 외교부 / 주관 KOICA·KF·한·아프리카재단)
- **부문**: 제품 또는 서비스 개발
- **접수**: ~2026. 7. 13.(월) 18:00 / 국민생각함 또는 이메일(opendata@kf.or.kr)

## 한 줄 요약
신흥시장·ODA 진출의 정보·제안 비용을 1/10로 낮추는, **출처 각주형(RAG) 설명가능 AI** 진출 파트너.
