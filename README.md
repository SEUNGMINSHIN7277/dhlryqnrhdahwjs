# 케이서클(K-Circle) — 2026 외교 공공데이터·AI 활용 경진대회 출품작

> **"공공데이터를 소비하는 서비스가 아니라, 공공데이터를 살아있게 만드는 서비스"**
> 외교부가 12년간 조사해 온 지구촌 한류 동호회 현황 지도(2.25억 팬, 1,748개 동호회)를 처음으로 **'살아있는 공공외교·수출 인프라'** 로 바꾸는 한류 플랫폼.

## 응모 정보
- **대회**: 2026년 외교 공공데이터·AI 활용 경진대회 (주최 외교부 / 주관 KOICA·KF·한·아프리카재단)
- **부문**: 제품 또는 서비스 개발 · **접수 마감: 2026. 7. 13.(월) 18:00** / 국민생각함 또는 이메일(opendata@kf.or.kr)

## 한 문장
한류 동호회(조직된 팬덤) × 중소 K-브랜드(수출의 72.5%) × 재외공관(184개)을 잇고, 그 실측 데이터를 멈춰 있는 국가 통계(『지구촌 한류현황』, 2023년판이 최신)에 되돌려주는 B2B 플랫폼.

## 구조: 하나의 데이터 엔진, 세 개의 얼굴, 하나의 루프
| 구성 | 역할 | 수익/기능 |
|---|---|---|
| 데이터 엔진 | KF 동호회·한류현황 12년 패널 + 외교부 8종 오버레이(ISO2 마스터 조인) → 국가별 매칭 스코어 | — |
| 서클 아틀라스 | 중소 K-브랜드용 '국가별 K-진출 브리핑'(근거 각주 RAG) · **아프리카 4기관 조인 브리핑** | B2B 구독(첫 매출) |
| 서클 브릿지 | 동호회 자체 행사에 대한 브랜드 **후원** 매칭 + AI 제안서·현지어 행사 키트 생성(IP 가드레일·에스크로) | 수수료 15~20%(주 수익) |
| 서클 파트너 | 재외공관·KF용 행사 코파일럿 **무료**(산출물에 등록 링크 내장 → 동호회 온보딩 깔때기) | B2G = 유통 채널 |
| 서클 라이브 | AI 신호 지수 + 실측 로그 → **KF 『지구촌 한류현황』 조사 보완 환류**(시그니처) | 해자 |

## 심사 루프 검증 (3인 패널 × 3라운드)
후보 9종 → Round 1 전원 불합격(최고 74) → 진화 지시 이행 → Round 2 조건부 통과(85/87/84) → 조건 9건 반영 → **Round 3 최종: J1 90 / J2 90 / J3 90, 치명결함 0, 전원 통과**. 전 과정은 `기획서/아이디어_발굴_심사표.md` 참조.

## 데이터 조회 관련 고지
data.go.kr·MOFA 포털은 봇 차단(WAF)·실행환경 이그레스 정책으로 직접 접근이 차단되어, 데이터셋 ID·엔드포인트·필드는 검색엔진 색인 + 오픈소스 클라이언트 코드 교차검증으로 확인(정책 우회 미시도, 여행경보·재외공관 계열은 실제 필드 키까지 ground-truth). 실서비스는 공공데이터포털 활용신청·인증키로 확보. 상세: `데이터/공공데이터_카탈로그.md`.
