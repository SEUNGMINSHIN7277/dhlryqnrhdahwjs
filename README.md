# 디딤(DIDIM) — 2026 외교 공공데이터·AI 활용 경진대회 출품작

> **AI 신흥시장·개발협력(ODA) 진출 인텔리전스 플랫폼**
> 외교부·KOICA·KF·한·아프리카재단의 개방데이터를 AI로 융합해, 한국 중소기업·소셜벤처·청년의 신흥시장 진출을 돕는 B2B SaaS.

## 응모 정보
- **대회**: 2026년 외교 공공데이터·AI 활용 경진대회 (주최 외교부 / 주관 KOICA·KF·한·아프리카재단)
- **부문**: 제품 또는 서비스 개발
- **접수**: ~2026. 7. 13.(월) 18:00 / 국민생각함 또는 이메일(opendata@kf.or.kr)

## 한 줄 요약
신흥시장·ODA 진출의 정보·제안 비용을 1/10로 낮추는, **출처 각주형(RAG) 설명가능 AI** 진출 파트너.

## 데이터 조회 관련 고지
data.go.kr·MOFA 포털은 봇 차단(WAF) 및 실행환경 이그레스 정책으로 직접 접근이 차단되어, 데이터셋 목록·ID·필드는 검색엔진 색인 + 오픈소스 클라이언트 코드 교차검증으로 확인했습니다(정책 우회는 시도하지 않음). 실서비스는 공공데이터포털 활용신청·인증키로 데이터를 확보합니다. 자세한 내용은 `데이터/공공데이터_카탈로그.md` 참조.
