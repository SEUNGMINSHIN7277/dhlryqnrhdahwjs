## 1. 제품(서비스)의 목적·배경 및 필요성

### 1.1 문제 정의 — "다들 같은 레드오션 지도를 보고 있다"
- 중소기업 해외진출 애로 **1위 '현지 정보 부족', 2위 '정부 지원제도 미흡'**. 바이어 발굴(34.6%)·해외시장 정보 부족(33.4%)·글로벌 역량 미흡(19.6%)이 반복 지적됨.
- 그런데 시중의 진출 정보는 **GDP·시장규모 같은 '레드오션 지표'** 뿐 → 모두가 같은 큰 시장으로 몰려 경쟁만 심화. **정작 한국이 남들보다 유리한 곳을 알려주지 않음.**
- 한국에는 **'남들에게 없는 진출 자산'** 이 있다: 한류 팬덤, 세종학당·한국어 학습자, 재외동포, KOICA 개발협력 실적, 재외공관 네트워크. 그러나 이 **소프트파워 자산이 어느 시장에 얼마나 깔려 있는지 아무도 지도화하지 않았다.**

### 1.2 핵심 통찰 — "소프트파워가 뿌리내린 곳 = 저비용 진입 시장"
- 한류·한국어·개발협력이 강한 나라일수록 한국 제품·서비스에 대한 **호감·신뢰·인지도(진입장벽↓)** 가 이미 형성돼 있음.
- 그런 곳 중 **아직 한국 기업의 사업 진출은 비어있는 시장 = '소프트파워 화이트스페이스'** 가 곧 **가장 유리한 블루오션**.
- 이걸 찾으려면 **KF(문화)·KOICA(개발협력)·외교부(공관·동포)·한·아프리카재단(현지기업)** 데이터를 국가 단위로 융합해야만 함 → **오직 이 대회 데이터로만 가능.**

### 1.3 시장·정책적 필요성
- 2026년 우리나라 ODA 예산 약 **2조 1,852억원**(KOICA 약 1조 1,389억원) + **400억 달러 이상** MDB 조달시장. 중소기업의 **46.1%가 신흥시장 개척 의향**.
- 예산 효율화 기조 속 **민간·중소기업의 개발협력 참여 확대·성과 제고**가 중요 → 진입 비용을 낮추는 디지털 인프라 필요.
- 4개 기관이 **양질의 데이터를 이미 개방**했으나 흩어져 있어 활용 난망 → **AI 융합으로 '활용의 마지막 1마일'을 연결**할 필요.

## 2. 제품(서비스)의 기능 및 특징

### 2.1 제품 개념 — 우리만의 시그니처
> **디딤 = 「소프트파워 진출지수(SWI)」 엔진 + AI 인텔리전스 + 실행형 워크스페이스**
> "GDP가 아니라 **한국의 소프트파워 발자국**을 나침반 삼아, 블루오션과 현지 파트너를 찾아준다."

### 2.2 ★핵심 특색: 소프트파워 진출지수 (SWI, Soft-power Whitespace Index)
국가(c)×분야(s) 단위로 산출하는 **고유 IP 지표**:

```
SWI(c,s) =  친한자산 A(c)  ×  사업공백 G(c,s)  ×  접근성/리스크 R(c)

· 친한자산 A(c)  = 한류 동호인·동호회(KF 15076250) + 한국어·세종학당·한국학 밀도(KF 15041591,15075335)
                  + 공공외교 사업(KF 15099202) + 재외동포·공관 접근성(외교부 15075354)
                  + KOICA ODA 사업·협력 밀도(KOICA 15058772,15075386)   ← 높을수록 '친한(親韓)'
· 사업공백 G(c,s) = 1 − 정규화(해당 분야 한국 민간진출·현지 한국기업 밀도)  ← 비어있을수록 높음
· 리스크 R(c)     = f(여행경보 alarm_lvl 15095500, 안전정보 15000760)      ← 과도 고위험은 감점
```
→ **SWI가 높은 곳 = "친한 자산은 높고, 사업은 비었고, 접근 가능한" 우선 진출 블루오션.**
→ **"온기(溫氣) 지도"** 로 시각화: 국가를 친한도(따뜻함)×사업공백으로 매핑, 한눈에 블루오션 식별.

> **왜 복제 불가능한가**: KOTRA·무역협회식 일반 시장데이터로는 A(c)의 '친한 자산'을 절대 계산할 수 없음. 오직 **KF+KOICA+외교부+한·아프리카재단 4개 기관 데이터 융합**으로만 산출되는 지표 → 이 대회 데이터가 곧 우리의 해자.

### 2.3 시스템 아키텍처
```
[공공데이터 4개 기관] ─► [① ETL·ISO국가코드 표준화] ─► [② SWI 엔진 + AI 인텔리전스]
 외교부/KOICA/KF/한·아프리카재단                          · SWI 산출·랭킹(온기 지도)
                                                          · RAG+LLM(출처 각주)
                                                          · 리스크 스코어링/멀티에이전트
                                                                     │
   [5대 모듈] 디딤 컴퍼스 · 디딤 인텔 · 디딤 코파일럿 · 디딤 커넥트 · 디딤 세이프
                                                                     ▼
                              [사용자] 중소기업·소셜벤처·컨설팅사·대학·공공
```
- **공통 조인키 = ISO 3166-1 국가코드(`country_iso_alp2`)**, 외교부 국가표준코드(15091117)를 마스터로 4개 기관 데이터 결합.

### 2.4 5대 핵심 기능 모듈
**① 디딤 컴퍼스 — SWI 기반 블루오션 추천 (시그니처)**
- 기업 프로필(업종·역량) 입력 → **SWI로 '당신에게 유리한 화이트스페이스 국가·분야 Top N'** 을 온기 지도와 근거(어떤 소프트파워 자산이 받쳐주는지)와 함께 추천. *뻔한 큰 시장이 아니라, 한국이 남들보다 유리한 곳을 콕 집어줌.*

**② 디딤 인텔 — 국가·리스크 진출 브리핑**
- **외교부 국가기본정보(15000830)·여행경보(15095500)·안전정보(15000760)·입국요건(15075345)** + **KOICA 개발협력동향(15075386)** + **한·아프리카재단 250대기업(15099200)** 을 LLM이 종합해 브리핑 자동 생성. **모든 문장에 출처 각주(RAG)**.

**③ 디딤 코파일럿 — 제안서·사업계획 AI 초안**
- **KOICA ODA 연구정보(15052906)·국별사업 보고서(15052832)·MOFA LOD 국가정보** 를 근거(RAG)로 개념노트·로그프레임·SDGs 매핑 초안 생성.

**④ 디딤 커넥트 — 현지 파트너·친한 네트워크 (양방향)**
- **한·아프리카재단 스타트업 디렉터리(15099203)·250대기업(15099200)** 에서 **현지 파트너 후보를 실제로 리스트업**(한국기업↔현지기업 양방향 매칭 = 상생).
- **KF 한류 동호회(15076250)·세종학당/한국학(15041591)·공공외교(15099202)** 를 **현지 진입 거점(친한 네트워크)** 으로 연결.
- **KOICA 봉사단 파견기관(15076248)**·외교부 **공석/JPO(15057115·15058737)** 로 글로벌 인재 연계.

**⑤ 디딤 세이프 — 파견 안전관리(Duty of Care)**
- **외교부 여행경보(15095500)·히스토리(15059195)·안전정보(15000760)·재외공관(15075354: `embassy_lat/lng`,`urgency_tel_no`)** + **KOICA 현지안전정보(15099207)·파견국 안전이슈 월력표(15076240)** 로 실시간 모니터링·위기 시 최근접 공관 연계.

### 2.5 AI 기술 특징
- **SWI 산출**: 다출처 정규화·가중합 + 시계열 리스크 보정. 설명가능하게 "왜 이 점수인지" 근거 데이터 표기.
- **RAG 출처 각주**: 모든 AI 응답에 공공데이터 출처 표기 → 환각 억제·신뢰성.
- **멀티에이전트**: 'SWI 발굴 → 국가 분석 → 파트너 매칭 → 제안서 초안'을 한 흐름으로.
- **한·영 이중언어.**

### 3.2 데이터 확보의 지속성·활용 범위·가공

- **활용 범위·준수**: 상업적 재이용 허용 범위 내, 출처표시(각주 자동), 개인정보 미포함 데이터 위주.

## 4. 기존 제품(서비스)과의 차별성 및 독창성

- **① 복제 불가능한 고유 IP '소프트파워 진출지수(SWI)'**: 4개 기관 데이터를 융합해야만 산출 → KOTRA·무역협회의 일반 시장데이터로는 원천 계산 불가. **이 대회 데이터가 곧 진입장벽.**
- **② 관점의 전환(레드오션→화이트스페이스)**: '큰 시장'이 아니라 '한국이 유리한 빈 시장'을 추천하는 **역발상 나침반**. 시중 어떤 서비스도 제공하지 않는 결과물.
- **③ 소프트파워의 자산화**: KF 한류·한국학·동호회 데이터를 '문화 통계'가 아니라 **시장 진입 자산 A(c)** 로 재해석 → 창의적 데이터 재사용.
- **④ 양방향 상생 매칭**: 한·아프리카재단 스타트업·기업 데이터로 **현지 파트너를 실제 연결**(일방향 정보제공이 아닌 상생 마켓).
- **⑤ 정책이 이미 검증한 수요**: 정부가 만든 KF×KOICA 융합데이터(15099199/15099215)를 **'공백 탐지'로 처음 productize**.
- **⑥ 출처 각주형 설명가능 AI(RAG)**: 정부 데이터 신뢰성 계승.

## 5. 기대효과 (사회적 가치 창출)

- **상생협력**: 대·중소·소셜벤처 컨소시엄 + **한국기업↔현지(아프리카) 기업 양방향 상생**, 지자체·대학 연계.
- **일자리 창출**: ①블루오션 선점으로 중소기업 해외매출·고용 ②청년의 글로벌·개발협력 커리어(봉사단·JPO 연계) ③**수원국 현지 기업 성장·고용**.
- **ESG·SDGs**: 개발협력 참여 확대 = 기후(E)·빈곤·보건·교육(S)·거버넌스(G) 기여. 예산 효율화 시대 **민간 주도 ODA 성과 제고**.
- **국격·소프트파워 선순환**: 한류→비즈니스→개발협력이 서로를 키우는 선순환. K-브랜드·한국형 개발경험 확산.
- **공공데이터 가치 실현**: 흩어진 외교·개발협력 데이터를 **고유 지표로 재창조** → 데이터 경제 활성화.
